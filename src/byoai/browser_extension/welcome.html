Coriqo Shield

Shield checks your AI messages for secrets and personal details, and notes that you sent one.

Please read this before turning it on. Nothing is recorded until you agree.

Where it watches

Only when you send a message on claude.ai, chatgpt.com (and chat.openai.com), gemini.google.com or copilot.microsoft.com (and copilot.com, copilot.cloud.microsoft, and m365.cloud.microsoft/chat). No other site.

What it records

  • which app you used,
  • when you sent the message,
  • how many characters it was,
  • which tools the AI ran for its reply, such as web search, by name, and how many sites a search returned.

It also records which of Shield's rules a message matched (for example "email address"), by name, never the matching text. That is all. The message text is read in the page and thrown away. By default it is not stored and not sent to Shield or anywhere else. If you turn on keeping a redacted preview in Shield's Settings, the first 200 characters stay on this computer.

What it changes

On claude.ai and chatgpt.com, before your message leaves the page, emails, card numbers, phone numbers, SSNs, wallet addresses and API keys are replaced with labels such as [redacted-email], so the AI never receives them. If your Shield is set to stop high-risk messages, a message carrying a password or an executable file name is not sent at all and the chat shows an error.

Your Shield's settings decide this: "Record only" leaves messages unchanged. On gemini.google.com and Microsoft Copilot (copilot.microsoft.com, copilot.com, copilot.cloud.microsoft and m365.cloud.microsoft/chat) the extension cannot rewrite what the page sends, so it checks the message box when you press Enter, click send or submit the form, and replaces the details there. This is best effort and not yet confirmed on every page. If it cannot tell which box is the message box, the extension popup says so, and the message is not checked.

Where it goes

To the Shield program running on this computer (127.0.0.1). The extension has no other destination: no server of ours, no analytics, nothing over the internet. What Shield does with its own record is described in its documentation.

You need Shield running

This extension is the browser side of Shield, a separate program you install on this computer (byoai-shield). Without it, nothing is recorded; a few messages are held for a short while and then dropped.

Sites your administrator adds

If your administrator switches on another AI chat site in Shield (today only chat.mistral.ai or chat.deepseek.com), the popup tells you which one and asks Chrome for your permission for that one site. Nothing runs there until you allow it. To do this the extension has the scripting permission, which it uses only to add its own checking scripts to that site. It never asks for access to all sites.

Turning it off

Turn capture off any time from the toolbar popup. Turning it off also removes anything still waiting to be sent. Read the full privacy notice.

"Not now" leaves the extension installed but doing nothing. You can change your mind from the popup.

Capture is on

Start Shield with byoai-shield if it isn't running. Open the extension popup any time to see whether it is working, or to turn capture off. You can close this tab. Pages that were already open need a reload before they are covered.

Capture is off

Nothing will be recorded. To turn it on later, open the extension popup and choose "Review and turn on". You can close this tab.
